# Item Materials

Reference for the `material` field in item JSON definitions. Use the integer ID value.

Valid range: **0–96**. ID 0 is a sentinel meaning "undefined" (material resolved at runtime from contents). ID 24 is unused. Maximum vanilla value is 96.
